# Eye Tracking Mouse Control

A Python project that uses gaze tracking to control the mouse pointer based on eye movements. The system supports calibration to dynamically set the screen center.

## Features
- Gaze-based mouse control using the `GazeTracking` library.
- Calibration mode: Look at the center of the screen and press `C` to set the reference point.
- Smooth and responsive mouse movements.
- Blinking and gaze direction detection.
